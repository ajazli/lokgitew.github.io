# Mobile Customer Journey Design

## Goal

Improve the existing Lok Gitew website for mobile visitors who want to decide quickly: view the menu, reserve a table, get directions, or contact the cafe.

## Approved Scope

- Keep the current brand look and one-page structure.
- Add a mobile sticky action bar with Menu, Reserve, Directions, and WhatsApp actions.
- Make the hero more immediately useful with clearer opening-hours and Thursday-closed messaging.
- Add lightweight menu shortcuts above the existing menu-book image viewer.
- Add reservation guidance that explains confirmation timing, last booking expectations, and Thursday closure.

## Design Direction

This is a pragmatic UX pass, not a full visual redesign. The site already has a strong food-forward visual style, so changes should feel native to the existing orange/black brand, typography, and section rhythm. New elements should be compact, useful, and mobile-first.

## Constraints

- Static HTML, CSS, and JavaScript only.
- No new assets or backend changes.
- Do not rebuild the full menu as structured data in this pass.
- Preserve existing reservation behavior, including disabled Thursdays.

## Success Criteria

- Mobile users can reach Menu, Reserve, Directions, or WhatsApp from anywhere.
- First viewport communicates hours and Thursday closure clearly.
- Menu section gives faster category orientation before users flip through image pages.
- Reservation form makes key rules clearer before submission.
- Existing desktop layout remains visually consistent.
